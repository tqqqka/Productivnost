# Продуктивность

Android-приложение против залипания в телефоне: полноэкранные напоминания
поверх любого приложения, воксельный сад, который растёт за время без экрана,
сессии учёбы с блокировкой, чистка галереи и продление приложений отжиманиями.

**Готовый APK:** [`release/productivnost-1.1.apk`](release/productivnost-1.1.apk) · 47 МБ · Android 8.0+ · arm64-v8a и armeabi-v7a

> В репозитории есть второе приложение — **[Островок](shtorka/README.md)**: Dynamic Island
> с iPhone вокруг капли камеры (музыка, звонки, таймеры, запись, навигация, уведомления).
> APK: [`release/ostrovok-2.3.apk`](release/ostrovok-2.3.apk) · 0.8 МБ.

## Что внутри

### Напоминания поверх экрана
Приходят только когда телефоном действительно пользуются: интервал отсчитывается
по накопленному экранному времени, а не по часам, поэтому за ночь ничего не копится.

| Напоминание | Когда |
|---|---|
| Вода, разминка, прогулка, взгляд вдаль | каждые 30 минут экранного времени (настраивается) |
| Почисти зубы | каждый день в 21:30 |
| Сходи помойся | через день в 20:30 |
| Пора спать | с 21:00 до 22:00 каждые 10 минут |

Звук — сгенерированные колокольчики (`res/raw/chime_*.wav`): мягкая атака,
длинный хвост, никакого резкого будильника. Ночное напоминание звучит ниже и тише.
Любое напоминание можно отложить на 5 минут.

### Дерево от зависимости
Выбираешь длительность и разрешённые приложения, сажаешь семечко — и воксельное
дерево растёт в реальном времени. Откроешь что-то не из списка — росток засыхает,
сессия отменяется.

- 30 минут → 1 дерево, 1 час → 2, 1.5 часа → 3, максимум 2 часа → 4
- Пять видов: дуб, сосна, сакура, клён, берёза
- Лаунчер, звонилка и настройки заслонку не роняют

### Деревья учёбы
Помодоро 25/5 (интервалы настраиваются). Во время работы чужие приложения
закрыты заслонкой, в перерыв телефон свободен. Сессия идёт, пока сам не нажмёшь
«Завершить» — и тогда вырастает по дереву за каждый полностью закрытый блок.
У деревьев учёбы своя палитра и стопки книг у корней.

### Сад
Одна большая воксельная грядка: квадрат клеток, повёрнутый углом к зрителю и
слегка наклонённый. Каждое выросшее растение занимает свою клетку, пустые клетки
стоят вспаханными и ждут. Щипок приближает, перетаскивание двигает грядку, тап по
дереву открывает его карточку. Всё выросшее за всё время остаётся здесь навсегда.

### Перенос прогресса
Кнопка «Сохранить прогресс» в настройках складывает сад, привычки, лимиты и
настройки в один JSON-файл, «Загрузить прогресс» возвращает их обратно. Файл
переживает переустановку и обновление приложения.

### Чистка фотографий
Сканирует до 3000 последних снимков и раскладывает по кучам:

- **точные дубликаты** — совпадает и вес, и перцептивный хеш;
- **похожие серии** — расстояние Хэмминга ≤ 6 и съёмка в пределах 5 минут;
- **скриншоты**;
- **тяжёлые файлы** — от 8 МБ.

В каждой группе лучший кадр (по разрешению и весу) помечен звёздочкой и не
выделяется под удаление. Удаление всегда подтверждает система — на Android 11+
через `MediaStore.createDeleteRequest`. Ничего никуда не отправляется.

### Продление приложений отжиманиями
Приложению можно задать дневной лимит. Когда время кончилось, появляется
заслонка с кнопкой «Продлить отжиманиями»: фронтальная камера считает повторения
по углу в локте (ML Kit Pose), одно отжимание — 2.5 минуты (настраивается).

## Как всё устроено

```
app/src/main/java/com/tihon/productivnost/
├── core/            модели, хранилище (StateFlow + SharedPreferences), сессии, бэкап
├── voxel/           воксельный движок: генератор растений, рендер, сцена сада
├── service/         фоновый сервис, оверлеи поверх экрана, звук, уведомления
├── feature/
│   ├── pushups/     CameraX + ML Kit Pose, счётчик отжиманий
│   └── cleanup/     сканер галереи, перцептивный хеш, удаление
├── ui/              тема, компоненты, экраны
└── util/            список приложений, разрешения, форматирование
preview/             JVM-инструмент: рисует те же растения в PNG, не собирая APK
```

### Воксельный движок
Растения генерируются процедурно и детерминированно: одна и та же семечка всегда
даёт одно и то же дерево, поэтому в саду хранится только `seed`, а не геометрия.

Рендер — ортографическая проекция с алгоритмом художника. У каждого кубика видны
ровно три грани, а проекция линейна, поэтому смещения восьми углов считаются один
раз на кадр, и на каждый воксель остаётся только сложение. Воксели, у которых все
шесть соседей уже выросли, не рисуются вовсе — отсечение учитывает стадию роста,
поэтому остаётся корректным и у наполовину выросшего дерева.

Результат кешируется в bitmap и пересчитывается только при изменении роста,
поворота или размера; каждый кадр остаётся лишь дешёвое покачивание на ветру.
Разрешение растра ограничено 768 px — воксели крупные, апскейл незаметен.

Сад устроен иначе: земля плоская, поэтому клетки рисуются напрямую тремя гранями
на клетку, а растения кладутся сверху заранее подготовленными спрайтами. Спрайт
считается один раз в фоновом потоке и дальше просто копируется, поэтому кадр
остаётся дешёвым и при сотне деревьев. Клетки идут по диагоналям от дальней к
ближней — боковые грани внутренних блоков закрывает следующий блок, наружу торчит
только передний край грядки.

Посмотреть на растения и сад без телефона:

```bash
./gradlew :preview:run     # /tmp/voxel_preview.png и /tmp/garden_*.png
```

### Наблюдение за экраном
Один фоновый сервис с адаптивным тиком (0.8 с при активной сессии, 2.5 с обычно,
4 с при погашенном экране). Переднее приложение определяется по `UsageStatsManager`;
события приходят только в момент переключения, поэтому при долгом сидении в одном
приложении используется снимок статистики и последнее известное значение.

Заслонка и напоминания — окна `TYPE_APPLICATION_OVERLAY` с Compose внутри
(собственный `LifecycleOwner`, чтобы Compose работал вне активити).

Прежде чем засчитать нарушение, сессия даёт 2.2 секунды форы — иначе случайный
свайп по системной шторке ронял бы дерево.

## Сборка

```bash
./gradlew :app:assembleRelease
```

Нужен Android SDK 35 (`local.properties` → `sdk.dir`) и JDK 17+.

Релиз подписан самоподписанным ключом `keystore/productivnost.jks`. Ключ
в репозиторий не коммитится: если положить его рядом, релиз подпишется им,
если нет — соберётся отладочной подписью. Ключ важно сохранить: без него
обновление не встанет поверх уже установленного приложения, придётся удалять
и ставить заново. Пароли по умолчанию (`productivnost`) можно переопределить
в `~/.gradle/gradle.properties`:

```properties
productivnost.storePassword=...
productivnost.keyAlias=...
productivnost.keyPassword=...
```

x86-архитектуры исключены из сборки: нативные библиотеки ML Kit весят по ~20 МБ
на каждую, а на телефонах они не нужны.

## Установка

APK не из Play Store, поэтому при установке нужно разрешить установку из этого
источника. После первого запуска приложение попросит два обязательных разрешения:

- **Доступ к статистике использования** — без него не видно, каким приложением
  ты пользуешься, и заслонка не сработает;
- **Поверх других приложений** — без него не будет ни полноэкранных напоминаний,
  ни блокировки.

Камера нужна только для отжиманий, доступ к фото — только для чистки галереи.
Если система усыпляет приложение, стоит отключить для него экономию батареи —
иначе напоминания начнут опаздывать.
